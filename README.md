# Craftov · 我的世界搜打撤

Craftov 是一个 Paper 1.21.11 插件，在 Minecraft 里实现「搜索 · 战斗 · 撤离」玩法：带装备进入地图，搜索物资、对抗 AI 敌兵与其他小队，活着撤离后战利品才真正属于你。

地图、物品、界面、贴图与音效都是原创并由脚本程序化生成，不使用任何现有游戏的素材或名称。界面和 HUD 的中文用 10 像素点阵字体 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)（SIL OFL 1.1）绘制，`tools/art/pixelfont.py` 把用到的字形烘焙进 `tools/art/fonts/`。枪械模型由 [Quaternius 的 Ultimate Gun Pack](https://opengameart.org/content/low-poly-guns-pack)（CC0 公有领域）转换而来：`tools/art/meshvox.py` 把网格体素化并合并成 Minecraft 能用的方块元素，结果保存在 `tools/art/voxguns/`。
地图、物品、界面、贴图与枪声以外的音效都是原创并由脚本程序化生成，不使用任何现有游戏的素材或名称。枪声来自真实枪械的 CC0 录音（[The Free Firearm Sound Library](https://opengameart.org/content/the-free-firearm-sound-library) 和两段 Freesound 消音枪录音，见「许可」），由 `tools/art/gunsamples.py` 切出单发并处理成各距离的版本。枪械模型由 [Quaternius 的 Ultimate Gun Pack](https://opengameart.org/content/low-poly-guns-pack)（CC0 公有领域）转换而来：`tools/art/meshvox.py` 把网格体素化并合并成 Minecraft 能用的方块元素，结果保存在 `tools/art/voxguns/`。

## 一键开服（玩家输入 IP 即可游玩）

需要：Java 25（BetterHud 需要）、`curl`、`python3`、`unzip`。

```bash
./server/setup.sh          # 正式服：正版验证，资源包地址自动探测公网 IP
./server/run/start.sh      # 启动（默认 4G 内存，可用 MEMORY=8G 调整）
```

脚本会自动下载 Paper 1.21.11、CraftEngine 26.9.2、BetterHud，安装 Craftov 并写好配置：

- 资源包由 CraftEngine **托管在 Minecraft 同一个端口**上，玩家进服时自动弹出下载提示，接受后即可游玩，不需要额外开放端口或网盘。
- 公网 IP 检测失败或服务器在 NAT 后面时，用 `./server/setup.sh --ip 你的公网IP或域名` 指定资源包地址。
- 本地测试：`./server/setup.sh --local`（离线模式，资源包地址为 127.0.0.1）。

首次启动会自动生成大厅与内置地图「锈港」（约 1 秒），之后玩家进服就会落在大厅。

## 测试地图「试验场」与测试模式

首次启动除了「锈港」还会生成一张功能测试地图「试验场」（120×104，白天），所有功能都在几步路以内，并且立了告示牌说明。**试验场只对测试模式和管理员开放**：其他玩家在部署菜单里看不到它，`/cv queue` 也排不进去；小队排试验场时每个队员都要有权限，等待期间关掉测试模式的话出发时会被取消。部署菜单默认选第一张非测试图（锈港），上次选过的地图也会重新校验。从南到北依次是：

- **出生区**：4 组出生点（三排同队同区，单排各自分开）。
- **测试军械库**：9 个固定内容的箱子，分别装着全部武器（满弹匣）和配件、弹药、头盔护甲、胸挂背包、医疗品、投掷物、钥匙、物资和收藏品，搜索很快。每局一份。里面的东西都标着「试验场物资」（`/cv items` 领的是普通物品，不算在内）：局内能正常使用，但没有价值，不能存仓库、卖给商人、放进安全箱，也不算收藏和撤离收益；撤离回大厅时会被收走（装在军械库胸挂 / 背包里的自己的物品会还给你，放不下的送到仓库邮箱）。试验场武器只用试验场弹药，自己的枪也装不进试验场弹药（换下来的子弹还是原来那种）；改枪台上试验场武器只能装武器箱里的试验场配件，和自己的配件不能混装。
- **物资箱长廊**：13 种物资箱各一个，品质有加成。
- **门禁室**：三间门禁房，分别要用三种钥匙开门，里面放着保险箱。
- **玻璃房**：普通玻璃会被子弹打碎，子弹打碎玻璃后继续飞（伤害 ×0.9），隔着玻璃第一发就能打中屋里的人；遮光玻璃防弹。
- **演练楼**：两层楼加天台，适合小队对抗。
- **坠落台**：5、10、15 格高，用来测试摔伤、骨折和夹板。
- **撤离点**：常驻、限时（开局 2 分钟后开放）、付费 ◈5,000、需拉闸（电闸在西边）、禁止背包、限员 2 人，六种并排。
- **敌兵区**：用墙隔开，有巡逻、驻守和狙击塔。机密和绝密难度下有首领「试验场教官」和两名护卫：开局就在岗位上休眠（原地不动、不理会别处的枪声，但有人闯到面前、在旁边开枪或打它们时会醒），60 秒后醒来并发出情报。

在 `config.yml` 中设置 `test.enabled: true` 开启测试模式。开启后所有玩家都能进试验场，也都能用 `/cv items`（大厅菜单和局内战术终端里也有按钮）打开**测试军械库**：免费领取任意物品、加 100 万块币、一键满血，或者模拟受伤（掉血并附加出血和骨折）。管理员不开测试模式也能用这两样。正式服请保持关闭。

## 玩法一览

| 系统 | 说明 |
|---|---|
| 转场与结算 | 进入对局和回到大厅时屏幕先黑一下再亮起（全屏黑场盖住世界加载的卡顿）。撤离后回到大厅约 1.5 秒打开结算界面（`raid.settlement-delay-ticks`）：结果（说明里有开火发数和急停射击发数）、用时、击败干员和敌兵、经验、排位分、带入价值、带出价值、净收益、新收藏品，以及带出的价值最高的 10 件物品；底栏是返回大厅、打开仓库和「再来一局」（直接打开部署界面）。阵亡也是同一个界面（看完击杀回放、观战结束回到大厅后打开），显示损失、击杀者和丢掉的物品。标题栏直接写着净收益和用时，聊天栏只留一行摘要（阵亡时在击杀回放之后、和受到的伤害一起立即发出，不等观战结束）。 |
| 消息与音效 | 一种消息一个渠道。操作结果和提示在动作栏，按优先级排队：倒地、救援、撤离和匹配倒计时最先，其次是操作结果，最后是提示，每条至少停留约 1.5 秒。菜单开着时动作栏被窗口挡住，点击的结果会同时写进刚点的按钮说明里（绿色 ✔ 成功 / 红色 ✖ 失败，停 2 秒；点的是下方背包时写在标题后面），失败有出错音。行动中的剩余时间警告、撤离点开放、随机事件和情报显示在罗盘下方的警报横幅上并有提示音，最后 10 秒和撤离倒计时的最后 10 秒有读秒音；击杀信息只发给击杀者和阵亡者各自的小队，显示在右上角的击杀栏（见「手感与反馈」），其他人不知道谁死在哪里（不再有全图击杀、撤离、部署人数和首领击杀播报）。聊天栏只留给不是你自己操作引起的事（成交、保险理赔、护航委托）和战后记录，消息前不再有 [Craftov]。伤害数字默认关闭（`combat.damage-numbers: false`）。界面有一套同一音色的音效：打开、关闭、点击、切换分页、确认、出错、领奖。 |
| 新手指引 | 新玩家进服后引导五步：打开战术终端、进入个人靶场、在改枪台装配件、开始行动、成功撤离。按任意顺序完成都算，提示的是第一个还没完成的步骤（出发时在聊天栏提示撤离）；大厅里每 45 秒在动作栏重复一次，局内和匹配中不重复，免得盖住击败、伤病这类提示。五步全部完成奖励 ◈20,000（指引出现之前就撤离过的老玩家不会看到）。 |
| 大厅 | 作战机库：开始行动、仓库、商人、交易行、干员、护航大厅、收藏室、排行榜站点，以及一个靶场。快捷栏第 9 格是战术终端（右键打开菜单，或 `/cv`）。 |
| 界面 | 所有箱子类菜单和物品栏都换成深色战术风格（深色窗体、凹陷的格子、琥珀色标题标记），胸挂 / 背包 / 护甲 / 头盔格有各自的空槽剪影，用不到的 2×2 合成区画成斜纹。菜单标题用 10 像素点阵字体，任何界面尺寸下都清晰。战术终端分「行动 / 备战 / 成长 / 社交」四区，「开始行动」是一个占 2×3 格的大按钮，底栏固定是说明、个人信息和关闭；部署、仓库、商人、搜索箱子、伤势、改枪台各有设计过的背景（伤势页是人形布局，改枪台把选中的枪放在展台上），翻页、切换商人分页、搜索完成时标题原地更新，界面不重开。每个按钮和分页都有自己的图标。物品的说明框边框是该物品的品质色（普通灰、优秀绿、精良蓝、稀有紫、史诗金、传说红），界面按钮的说明框是素色深灰。 |
| 配装 | 你在大厅的物品栏就是下一局的出战装备。物品栏第 2 行是**胸挂格**、第 3–4 行是**背包格**，装备胸挂/背包才会解锁。卸下胸挂/背包时里面的东西会跟着装进去。对局中存活时，在物品栏里把鼠标停在已装备的胸挂/背包上按 Q，会连同里面的东西一起丢出；大厅里和倒地时不能丢，在窗口外点击也不会丢出鼠标上的东西。关上物品栏（或断线）时鼠标上的东西会放回身上，拿起的胸挂/背包会重新装备。身上放不下的物品（比如领取或拆下的东西）在大厅里会放进仓库邮箱，在对局里掉在脚下。用鼠标拿在手上的物品也算携带：阵亡时进遗体，撤离时放回身上（放不下的进仓库邮箱）。 |
| 战备值 | 身上装备与物资的总价值，近战武器不算（第 3 格的刀死亡不会丢失，买再贵的刀也不能单靠它进机密）；部署菜单、主菜单和 HUD 显示的都是这个数。常规 / 机密 / 绝密 三档难度要求不同战备值（0 / ◈60,000 / ◈250,000），机密和绝密出发时另收入场费（◈32,000 / ◈43,000，约为这一档随机搜 10 个箱子带出物资中位数的 5%，`tiers.*.entry-fee`，常规免费，排队时余额不足会被拒绝；匹配成功后、地图加载完前掉线不扣，这段时间把块币花到付不起入场费的会退出本局）。难度越高物资越好、敌兵越强、首领出没。开箱的品质加成 = 难度本身的加成（常规 0、机密 1、绝密 2）+ 箱子在地图上的等级，加成越高稀有品质的权重越大。某类物品在抽到的品质上没有货时只往更低的品质找（找不到就少一件），不会变成更稀有的东西。 |
| 匹配 | 每张图、每档难度一个匹配池，同一时段排队的所有小队进同一局，互为敌人。单人或三人小队；三人模式可自动补位。排位赛只决定是否计排位分，不影响匹配。凑满小队数（默认 4，不超过地图出生点组数）立即出发，否则最早排队的人等满 30 秒后带上池中所有人出发；多出的小队直接开下一局。开局后不再加人。 |
| 入场运镜 | 镜头从地图上空俯冲到你的小队渗透点。运镜途中离不开镜头：按 Shift 没有反应，按数字键或滚轮打开的原版旁观菜单照样会弹出，但选人传送不会生效。部署 20 秒后还没落地的人（运镜出了问题）会直接放到渗透点（`raid.deploy-timeout-seconds`）；运镜途中对局被结束（`/cv end`）时，还没落地的人回到大厅，装备原样保留，退还入场费和保险费；运镜中掉线的人也一样，重新上线时人在大厅，装备和费用都已退回。 |
| 武器 | 11 把原创枪械（手枪、冲锋枪、步枪、轻机枪、霰弹枪、射手步枪、栓动狙击），全自动/三连发/单发/栓动/泵动，弹道、后坐力、扩散、伤害衰减、爆头（默认 2 倍，霰弹枪、射手步枪、狙击枪各自不同）；打手臂按 0.65 倍、打腿按 0.7 倍伤害（`combat.zone-multipliers`）。手臂是从开枪方向看过去躯干左右两侧的边缘，只在对方正面或背面朝你时才有；侧身对着你时打中躯干就算胸腹，由背心来挡。倒地、钻进 1 格高的缝里爬行或游泳时身体是平躺的，不再按高度分：朝前的 1/4 是头那一端、后 35% 是腿、中间前半是胸后半是腹，打在背上（命中框顶面）的左右边缘是手臂，打在侧面算胸腹。头那一端也不全是头：手臂向前伸在头两边，下巴下面露出胸口，所以从正面看过去左右边缘是手臂、最下面 1/4 是胸，只有中间偏上才是爆头。爬行的人正对着你时大约四成命中是爆头，斜对着更少，侧身时大多是胸腹，脚朝你时几乎都是腿。切枪要先拔枪：手枪最快，轻机枪和栓动狙最慢，拔枪期间不能开火、不能开镜；切走再切回也省不掉拉栓 / 泵动，连射累积的扩散照常慢慢回落。边走边打更散：每把枪有自己的移动散布（items.yml 的 `move`，全速走路时加在扩散上的度数，开镜时减半）：手枪和霰弹枪 1.5°、冲锋枪 2°、步枪 3–4°、轻机枪 5°、射手步枪和栓动狙 6°，所以走着开镜打 K47 扩散约是站定的 5 倍，走着用 AWR 基本打不中。按服务器测到的实际移动速度算（相对你当前能走的最快速度，开镜、负重、骨折变慢的人全力走也算走），走速的四分之一以下不算（`weapons.spread.move-deadzone`），静步和刚停下的最后几 tick 不受影响：按反方向键急停约 0.1–0.2 秒就能打准。下蹲更准，跳起来最散。结算界面的结果按钮说明里有「急停射击」：开火时移动没有影响精度的发数和比例。敌兵打移动中的你也更散（走路约 1.4 倍，冲刺更难打中）。后坐力是一个过程而不是一下跳：每发的镜头上跳六成在开枪那一 tick、四成在下一 tick（`weapons.recoil.first-tick-share`），开镜时后坐乘 0.6、潜行乘 0.8（`weapons.recoil.ads` / `sneak`）。后坐力会回落：停火约 0.15 秒后视角往开火前的准星飘回去，约 0.35 秒还回连射上抬的七成左右（每把枪不同），每 tick 最多回 1.2°（`weapons.recoil.return-max-step`），打完一整匣的长连射回得慢一些，自己已经压下去的部分不会再往下拉，也不会越过开火前的准星；回落途中对着同一处再开火，没还完的部分接着还，转去打别的目标则按新的准星重新算。延迟高时回落多等一个往返再开始；一边回落一边往下压时，回落会按你下压的速度提前停下，一般不会被拉过头（延迟 200ms 以上又突然猛压时仍可能多拉一两度）。全自动和三连发时每发后坐有两成只抬子弹、不抬镜头：连射越久弹着点越比准星高，但越往后涨得越慢（M4C 开镜第 10 发约高 0.6°、打完一匣约 1.4°，在 30 米处约高 0.3 / 0.7 米），停火约 0.45 秒后落回准星，所以压枪要比镜头上跳压得再多一点；单发、栓动、泵动不受影响，瞄准镜里对着哪里就打哪里。命中按你开枪时屏幕上看到的位置判定：服务器按你的延迟（往返 ping 再加 0.2 秒，最多 0.3 秒）把其他玩家和敌兵的位置倒回去再算，准星压住横移目标的身体就能打中，不用提前量；打中的部位也按你看到的姿势算（对方刚蹲下或刚站起来时，你打的是胸口就算胸口、打的是头就算头）；代价是对方刚躲进掩体后的这一小段时间里仍可能被打中。敌兵开枪不回溯。栅栏、围墙、栅栏门按看到的模型高度挡子弹（碰撞箱比模型高半格，以前躲在栏杆后露出的头打不中），草、花、告示牌不挡。敌兵和侦察无人机的视线也一样：栏杆、矮墙后露出的头它们看得见，隔着玻璃、玻璃板、铁栏杆也看得见（树叶要它已经知道你在那儿才看得穿），所以你能打到的位置它们也能还手；你只露出头和肩膀时，敌兵瞄露出来的部分而不是打掩体。 |

| 敌兵行动 | 敌兵会打开挡路的木门走过去，最后一个人过去约 2 秒、门口没人时再关上（玩家自己开的门不动）；铁门和本局还没解锁的门打不开，追到这种门前会守在门口，过几秒再找路。看着你钻进楼里关上门的敌兵会跟着开门进来。开枪时瞄你露出来、子弹又打得到的部位：胸口露着就瞄胸口，蹲在矮墙后只露头就瞄头；隔着栅栏它看得见你，但子弹打不穿，这时它挪位置找能打到的角度而不是往栏杆上扫（狙击手不挪也不开枪）；玻璃、铁栏和树叶你的子弹打得穿，它也照样隔着开枪（玻璃会被第一发打碎）；队友挡在射线上时先往旁边让开，子弹也会停在队友身上（不伤队友），所以盾兵身后的队友打不穿盾兵。敌兵的准头按目标处的米数算，远近一样准（常规约 0.6 米内、绝密约 0.3 米内，狙击手 0.1–0.2 米），超出手里枪的有效射程时只打一两发的点射；站在远处不动也不安全。被没发现的人打中时（子弹、刀或手雷都算），敌兵只知道攻击大概从哪边来（远处误差约 5 米）：它对射手的察觉一下涨一半、找人的视野远一半，转过去朝那里打几轮压制射击，一段段找掩体往那边推进（每处躲 2–4 秒，狙击手原地不动），并叫上 24 格内的队友一起过去，8 秒后再去那边搜查，所以在视野外放冷枪不再白打。首领和护卫开局就在岗位上，休眠到时间（锈港 90 秒）才醒来并发出情报，不再凭空刷进有人在搜的房间；休眠时不走动、不理会别处的枪声，但看见闯到面前的人、挨打（子弹、刀或手雷）、12 格内有枪声或爆炸（`ai.boss-wake-radius`）、或有同伴倒下时会全体醒来，第一颗手雷就会把它们全部炸醒。敌兵出生、巡逻和交战中的走位（后撤、侧移、往射手那边推进）都只去能站人的地方（两格高的空间、脚下是实心地面、在地图边界内），不会走进海里或卡在墙里，也不会在水里变成别的怪、窒息或淹死。 |

| 局内事件与夜战 | 约 30% 的对局是夜间行动：地图漆黑，敌兵视野减半，但开着战术手电会被更远处的敌兵发现。每局还会在中段随机发生两个事件：停电（需拉闸撤离暂时失效）、炮击（预警 20 秒后红圈内落炮）、敌方增援从地图边缘赶来、红烟标记的空投、首领带护卫转移，聊天栏会告诉你方位和距离。管理员可用 `/cv event <事件>` 手动触发。 |
| 击杀回放 | 阵亡后以击杀者的第一视角重看最后 6 秒（人形替身重演、带曳光和枪声，最后一秒慢放），之后才是结算和观战队友。回放就在进行中的对局里播放，替身只有阵亡的本人看得见，子弹、手雷和炮击都会穿过替身，替身也不会把人挤开。击杀者在这 6 秒里打中过你才有回放：流血、摔落、炮击致死而他最后一次打中你在更早之前时，直接进结算。按 Shift 跳过；`replay.enabled` 可关闭。阵亡的同一刻画面就固定在倒下的位置，不能飞也不能穿墙，直到回放开始（没有回放时是 5 秒后的结算）。阵亡后、回放和观战时都不能用原版旁观菜单传送到别的玩家身边；左键点人也换不了视角（画面固定时点队友或遗体、回放时点别的替身都没有反应，观战时只能看自己的队友，不能跟随敌人或敌兵）；观战队友时按 Shift 返回大厅。 |
| 每日任务 | 每天 04:00 刷新 3 个任务（击败敌兵、爆头、近战、首领、干员、搜索、撤离、指定地图、单局收益），完成即发块币和经验，全部完成另有奖励；未完成的可花钱更换。指定地图只会抽到能排的正式地图（不会是测试图），已领的任务所在地图被删除或改成测试图时会免费换成新任务。 |
| 断线重连 | 交战中（15 秒内打中过别人或被玩家、敌兵打中过，替身挨的打也算）关游戏或掉线直接判定阵亡，战报为「交战中断线」，遗体留在原地，击杀记给最后打中你的人。其他时候掉线，你会以**替身**留在原地：一个穿着你的皮肤、头盔、护甲、胸挂和背包的人，保持掉线时站立 / 蹲下 / 趴下的姿势，血量和你一样，掉线前身上的出血照常扣它的血，流血致死同样算阵亡。替身和你本人一样能被子弹、刀、投掷物打伤（同样算护甲和干员的护甲损耗加成；中弹同样会出血、骨折，出血接着扣替身的血，伤势等你重进后还在），队友没开友伤打不了它，敌兵不会主动去找它，敌方的声呐也会标出它；替身被打死就等于你阵亡，战报为「断线后被 X 击杀」，你本局的击杀和经验照常计入，遗体在原地、带着除近战武器外的全部装备，击杀照常记给对方。120 秒内重进会回到替身所在的位置，血量和护甲耐久取替身当时的状态，替身随即消失（替身刚挨过打的话，重进后马上再下线同样算交战中断线）；重进后有 2 秒不受伤害，也不能开火、用刀或投掷（开镜和换弹不受影响）；敌兵照常反应，看得见你的敌兵在这 2 秒里就会瞄准你，保护一结束就开火（刚落地时的 3 秒保护同样不能攻击，但之后约 12 秒内敌兵不主动找你，你先开火、投掷或打中人就不再等）。入场运镜中掉线的，运镜结束前重进会接着看运镜、和小队一起落地；运镜结束时替身出现在你的渗透点，之后重进则回到替身那里。超时视为失踪，替身倒下成为遗体（穿着你的皮肤、头盔和护甲），带着除近战武器外的全部装备。匹配成功后、地图加载完成前掉线只会退出本局，不扣入场费，装备和安全箱原样保留。服务器关闭时还在局内的人（包括断线等待重连的）整局作废，见「服务器维护」。 |
| 服务器维护 | 对局进行中服务器关闭时，仍在局内的人（存活、倒地、入场运镜中、断线等待重连的）**整局作废**：配装和安全箱恢复成出发时的样子（局内捡到的东西全部作废，用掉的弹药、药品也回来；交给别人、又被对方带出本局的不会再退回一份：对方撤离时带走的、阵亡时留在他安全箱里的都算，服务器崩溃时也一样。弹药、药品、贵重品这类可堆叠物品没有编号，按数量推算：对方带出的比他自己带进来的多出的部分，在你带进来、现在不在身上、也不是打掉或用掉的数量以内，算作你交给他的，所以你丢在局内的东西碰上对方另外捡到同一种时也可能少退。少退了什么，补偿邮件里会写明），入场费和保险费全额退还，每人还会收到一封系统邮件「服务器维护补偿」，写明作废的地图 / 难度、退还的费用、扣回的局内奖励和没有退回的物品（聊天栏也会简要说明），附件是 ◈5,000 补偿（`raid.void-compensation.money`，设为 0 只退费），在仓库邮箱里领取。作废的这局不计排位分、经验、任务进度和战绩（出发时加上的行动次数也撤回，局内完成每日任务拿到的奖励和升级奖励一并收回），局内领取的悬赏退回到被击杀者头上；他们局内掉落、放进箱子或留在地上的投保装备不再理赔；他们带队的护航委托按取消处理，赏金全额退回老板。同一局里已经阵亡或撤离的人照旧按原规则结算，不受影响，也不会收到补偿邮件。服务器意外崩溃（断电、进程被杀）时按同样的规则作废，在玩家下次上线时恢复配装和安全箱、退费并发补偿邮件，只处理一次。 |

## 操作

| 按键 | 作用 |
|---|---|
| 左键（按住） | 开火；全自动武器按住连发，准星压在近处的人、箱子、遗体上也不会断（相距 1.3 格以外总是如此，再近要看眼睛在方块里的位置）；三连发点一下就打完三发，打下一组要再点一次。M4C、SV9、V57 的射速对不上服务器 tick，全自动的枪声按两发（M4C）或三发（SV9、V57）一段播放，节奏均匀；听到几发就打出几发，所以全自动点一下至少出 2 / 3 发。冲刺时不能开火，停下后枪要约 0.25 秒才端起来，一直按着的话端起来就开火 |
| 右键（按住） | 开镜瞄准（ADS）：枪移到准星下方、扩散变小、移动变慢、视野放大；DM14、AWR 等带倍镜的枪显示瞄准镜并放大约 2.4 / 4.5 倍；松开即腰射 |
| Q | 换弹（弹匣打空时扣扳机也会自动换弹）；潜行 + Q 切换弹种 |
| 数字键 / 滚轮 | 切枪：枪要先端起来才能开火和开镜，手枪约 0.3 秒、冲锋枪 0.5 秒、步枪和射手步枪 0.6 秒、霰弹枪 0.7 秒、轻机枪和栓动狙 0.9 秒；拔枪时按下左键并按住不放，端起来那一刻就开火（切枪前就按着的要松开重按），武器面板上有拔枪进度。拔枪期间按左右键，手里的枪都保持腰间姿势：不会抬到瞄准位置（AWR、DM14 也不会提前收起枪身却没有镜子），也不会有枪口火焰和后坐动作。按住右键切枪的，端起来那一刻就开镜。切枪会打断换弹。AWR 开一枪后切走再切回，仍要等拉栓完（约 1.4 秒）才能开下一枪，R12 同理（约 0.85 秒） |
| F | 切换射击模式；拿刀时检视刀 |
| 鼠标中键 | 战术手电（需装在战术位）：关 → 常亮 → 爆闪。爆闪会让正对着灯的玩家白屏闪烁；敌兵约 1 秒内子弹明显变散，但照样走位还击，之后约 4 秒适应强光，一直照着也压不住它 |
| 潜行 | 静步：完全没有脚步声，敌兵听不到（正常走路 10 格、冲刺 24 格内会被听到），被看见也慢一半 |
| 潜行 + F | 释放干员技能 |
| 右键物资箱 / 遗体 | 搜索（手里拿着枪也行：3 格内准星对着箱子、遗体或靶场武器架时右键是打开，不开镜；箱子前面站着敌人或靶子时，右键是开镜瞄准他） |
| 医疗品拿在手上按住右键 | 使用（自动处理最危险的伤口），战术终端「伤势」查看每个部位 |
| 投掷物拿在手上按住右键 | 拉环：引信从这一刻开始计时（破片手雷 3.5 秒、震撼弹 2 秒、烟雾弹 1.5 秒），动作栏倒数剩余秒数，眼前有一串只有自己看得见的点标出现在松手雷会怎么飞（撞墙反弹也算在内），红点是它会爆炸的位置（`throwables.preview` 可关），走路和冲刺不受影响；松开右键扔出（潜行时轻抛）。捏得越久，扔出去炸得越快（可以空爆），捏过头会在手里爆炸。拉环后换成别的物品会插回保险销，雷还在身上。门、拉杆、按钮照常能用 |
| 对准倒地队友按住右键 | 救援 |
| 快捷栏第 9 格 | 战术终端：伤势、安全箱、撤离点情报、小队状态、技能、放弃行动 |

HUD（需要 BetterHud）的文字全部用 10 像素点阵字体按整数倍绘制，任何分辨率和界面尺寸下都清晰（大号数字用原版字体放大 2 倍）：

- 左下（聊天栏下方、快捷栏左侧）：生命面板。人形图按部位显示出血和骨折，生命值（60 以下变琥珀色、30 以下变红）和血条、体力条（过载时变红），头盔和护甲的等级与耐久条，右上角是伤病图标（出血 / 大出血、骨折、止痛中）。
- 右下（快捷栏右侧，和生命面板同高，不会被聊天栏压住）：武器面板（大厅靶场里也有）：枪名、弹匣（打空变红）／备弹，最下一行是射击模式和弹种，有提示时换成提示（换弹中、「[Q] 换弹」、无弹药）。换弹时面板底部是金色进度条，切枪后拔枪时是灰色进度条。不能开火时（比如大厅靶场外、正在换弹、没子弹）屏幕下方会说明原因。
- 左上：地图与难度、剩余时间（5 分钟内变琥珀色、60 秒内变红）、携带价值、最近的撤离点；下面一行是干员技能和冷却，再下面是小队栏，每个队友一行（生命或倒地 / 阵亡 / 已撤离 / 断线）。

`python3 tools/art/hudcheck.py` 按 16:9 和 21:9 的常见分辨率、界面尺寸 2 / 3 / 4 检查 HUD 面板不出屏、不压快捷栏、副手格和聊天区，受击和血迹画面中间透明。
- 右上（进度提示框下面）：击杀栏，最多 5 行，每行 5 秒（自己小队和交手小队的阵亡、自己击败的敌兵、队友消息）；准星上方是连杀徽记。
- 罗盘下方：警报横幅（剩余时间、撤离点开放、随机事件、情报）。
- 准星下方：交互提示（「[右键] 搜索 军用箱」「[按住右键] 救援 队友」，垫着一条暗色横条，亮色地面上也看得清），撤离、倒地、用药时是大号倒计时和进度条。

管理员可以用 `/cv hud <玩家>` 查看某人 HUD 上的警报、击杀信息、交互提示、战备值、剩余时间和伤病状态（给测试脚本用，假人看不到 BetterHud）。

## 指令

玩家：`/cv`（菜单）、`/cv deploy`、`/cv stash`、`/cv mail`（邮箱）、`/cv trader`、`/cv market`、`/cv secure`、`/cv leave`（取消匹配）、`/party invite|accept|leave|kick <玩家>`（也可以写成 `/squad`，不带参数时列出小队成员）。在个人靶场里 `/cv` 打开靶场武器架，`deploy`、`stash`、`mail`、`trader`、`market`、`secure` 要先离开靶场。

管理（`craftov.admin`，默认 OP；服务器是离线模式时 OP 只能从局域网登录，见「配置文件」末尾）：

- `/cv give <玩家> <物品ID> [数量]`、`/cv money <玩家> <数量>`
- `/cv raids`、`/cv end [对局ID]`（立刻结束）、`/cv tp <对局ID>`（旁观）
- `/cv injure <玩家> <head|chest|stomach|left_arm|right_arm|left_leg|right_leg> <light|heavy|fracture> [造成伤口的玩家]`（测试伤势；写了造成伤口的玩家时，这处出血算他打的，会顺延他的击杀归属）
- `/cv reload`（重载配置、物品、掉落表、地图）、`/cv lobby`
- `/cv feed <玩家>`：这名玩家击杀栏里的几条击杀（不论是否已经从屏幕上消失）和当前连杀数
- `/cv marketaudit [数量]`：交易行成交笔数最多的账号，附等级、交易行收入、余额和累计带出价值，用来查刷过交易行的账号
- `/cv ai [对局ID]`：列出对局里每个敌兵的位置、朝向、在做什么（休眠 / 交战 / 受击 / 掩护 / 追击 / 守候 / 警戒 / 搜刮 / 巡逻）、在打谁、对哪些玩家有几分察觉；`/cv ai spawn <patrol|guard|sniper|shield|operator> <x> <y> <z> [对局ID]` 在那里放一个就地驻守的敌兵（测试用）。对局ID也可以写对局世界名；不写时用自己所在的对局，或唯一一个进行中的对局
- `/cv lagcomp [on|off]`：临时开关命中延迟补偿（不带参数则切换），`/cv reload` 后恢复配置文件里的设置；用来对比开 / 关时打移动目标的手感
- `/cv hud <玩家>`：打印这名玩家 HUD 上的警报、击杀栏（还留着的最多 5 条，已经从屏幕上消失的也算）、交互提示、战备值、剩余时间和伤病状态；`/cv close <玩家>`：关掉这名玩家当前打开的界面（比如撤离后的结算界面）。两条都是给测试脚本和截图工具用的
- `/cv luck <玩家>`：查看玩家的个人运气（离线也行）：额度池、行为系数和它的四项来源、金 / 红保底计数、每件大奖物品的场次、补偿局还剩几局和 24 小时亏损到了阈值的多少。后面加 `quota <数量|+数量|-数量>`、`pity <GOLD|RED|大奖物品ID> <数量>`、`boost <局数>` 或 `reset` 修改（记进服务器日志）

## 制作自己的地图

不用圈地、不用写坐标，手持工具点方块就行：

1. `/cv editor world mymap_world` 创建一个空的建图世界（或把现成的世界文件夹放进服务器根目录后用同样的命令载入）。
2. 在里面盖好地图，然后 `/cv editor start mymap` 领取工具（新地图的 ID 和世界名一样，只能用小写字母、数字和下划线，3–32 个字符；以前用别的字符保存的地图照常能打开编辑）：
   - **出生点**：点方块放置，潜行 + 右键空气切换组号（同组 = 同一小队的出生位置）。
   - **撤离点**：潜行 + 右键空气切换类型（常驻/限时/付费/需拉闸/禁止背包/限员）。
   - **物资箱**：切换箱子类型（杂物箱、武器箱、医疗箱、保险箱……），朝向跟随视角。
   - **敌兵**（巡逻/驻守/狙击手）、**首领**。
   - **门禁/电闸**：点击铁门设为门禁（切换需要的钥匙），点击拉杆/按钮设为电闸，自动绑定“需拉闸”撤离点。
   - **删除**：删掉 3 格内最近的标记。
   - **扫描箱子**：把附近 64 格内的箱子、木桶等方块一键转换为物资箱。
   - **保存/边界**：右键保存；潜行右键两个角设置地图边界。保存时敌兵点或首领点离最近的出生点（水平距离）不到 30 格会提示，开服和 `/cv reload` 时也会在控制台警告：落地的小队还没迈步就会被打。
3. 所有标记都会以只有编辑者可见的悬浮文字显示。`/cv editor set name 我的地图`、`set minutes 20`、`set time dusk`、`set camera`（入场运镜中心）、`set test true`（设为测试图，只有测试模式和管理员能看到、能排）可修改属性，`/cv editor exit` 保存并退出。

地图保存在 `plugins/Craftov/maps/<id>.yml`，也可以直接编辑（`test: true` 即测试图；`proving.yml` 没写这个键时也按测试图处理）。手改出错（语法错误、拼错撤离点类型等）的文件不会被覆盖：这张图暂时不加载，文件原样保留并另存一份 `<id>.yml.broken`，控制台和管理员进服时会提示；修好后 `/cv reload`，或删掉文件让内置地图在下次开服时恢复默认。

## 配置文件

`plugins/Craftov/` 下：

- `config.yml`：新手装备、难度档、匹配、断线重连窗口与交战中断线判定（`raid.reconnect-seconds`、`raid.combat-logout-seconds`，后者设为 0 关闭）、服务器维护补偿（`raid.void-compensation.money`）、倒地时长、护甲减伤与耐久（`combat.armor`）、破片手雷弹片的穿透和护甲损耗（`throwables.frag`）、投掷物撞墙和落地的反弹（`throwables.bounce`）、拉环时的轨迹预览（`throwables.preview`）、刀砍手脚的伤害系数和检视时长（`combat.melee`）、移动散布的开镜系数和死区、下蹲 / 跳跃对扩散的影响（`weapons.spread`）、冲刺停下后枪要多少 tick 才端起来能开火（`weapons.sprint-recovery-ticks`）、切枪后各类枪的拔枪时间（`weapons.draw-ticks`，按 items.yml 里枪的 `action` 分类，单位 tick）、开镜 / 潜行的后坐系数、每发后坐分两 tick 的比例、后坐回落（速度和每 tick 上限）与连射时只作用在子弹上的那部分后坐（`weapons.recoil`）、枪声（`weapons.audio`：开枪者听到自己枪声的音量范围、近 / 中 / 远三档交叉淡化的距离、隔墙时闷声和原声的比例（隔墙效果在 `mid-far` 区间里逐渐消失）、每枪音量的随机起伏）、AI 强度（`ai.damage-multiplier` 是敌兵打中身体和四肢的伤害相当于玩家用同一把枪、同一种弹药的多少，默认 0.65，首领再 ×1.15，不受世界难度影响；敌兵爆头时只用枪的爆头倍率的一半（至少 1 倍），所以默认下敌兵爆头约为玩家爆头的三分之一（霰弹枪约 0.4）；以前对局世界是困难难度，敌兵实际打出的相当于 0.975，想保留那时的手感就改成 0.95 左右；`ai.aim-error` 是敌兵子弹落点离瞄准点多远，按目标处的米数算，远近一样（默认常规 0.6 米到绝密干员、首领 0.25 米，狙击手 `ai.sniper-aim-error` 0.2 到 0.1 米，目标在动时按实际移动速度放大，走路 ×1.4、冲刺约 ×1.5，刚开火的 3 秒内更散）；`ai.awareness` 是敌兵察觉玩家的快慢；`ai.dazzle` 是敌兵被爆闪 / 震撼弹晃到后的失准）、震撼弹白屏时长与全白期间的失明（`combat.flashbang`）、子弹打碎玻璃后保留的伤害和能打穿的方块（`combat.penetration`）、命中判定的延迟补偿（`combat.lag-compensation`：回溯 ping + `extra-ms`，最多 `max-ms`，`max-ms` 超过 1000 按 1000 算）、商人/交易行费率、免费补给、离线模式下 OP 能从哪些地址登录（`security`，见本节末尾）等。
- `items.yml`：全部物品（名称、品质、价值、枪械参数、弹药穿透、护甲等级、医疗效果……）。枪的 `recoil-return` 是停火后还回的后坐比例（0–1，默认 0.7），`move` 是全速走路时扩散增加的度数（没写时按枪的 `action` 取默认值）。
- `loot.yml`：每种物资箱的类别与品质权重，以及大奖物品（`jackpots`）各自的出现概率。
- `items.yml` 和 `loot.yml` 只在缺失时才从 jar 里复制，更新插件不会改动服务器上的这两个文件。文件开头的 `revision` 比新 jar 自带的低时，开服和 `/cv reload` 会在日志（以及执行 reload 的人）那里提示：价格、掉落权重等改动要先备份旧文件、换成新的（或把改动合并进去并把 `revision` 改成新值）才会生效。经济平衡（#22）把两个文件都升到了 revision 1，战斗修复（#26–#29）把 `items.yml` 升到 2，武器手感（#32–#34：射速、后坐和每把枪的 `recoil-return`）升到 3，枪感（#8：每把枪的移动散布 `move`）升到 4。
- `config.yml` 缺的键会回落到插件自带的默认值，已有的键不会被新版本改动。唯一的例外是入场费：#80 之前写下的 `config.yml`（难度档里还有 `max-shift`）里机密 / 绝密的入场费还是当时的 ◈8,000 / ◈20,000 时，开服会把它们改成插件自带的新值、删掉不再使用的 `max-shift`，其他行原样保留，旧文件留作 `config.yml.pre-80`（日志里有一条警告）；改过的入场费不动。
- `data/`：玩家档案与交易行数据（JSON）。旧版本的 `market.json` 在开服时会自动清空成交均价和成交记录（旧版本的参考价可能被刷高过），售价超过参考价 3 倍的挂单退回卖家邮箱（手续费不退）。
- `backups/`：玩家数据的 zip 备份。每天一份（`*-auto.zip`，最新一份满 `backup.interval-hours` 才做下一份，重启不会多做）和每次关服一份（`*-shutdown.zip`），分开保留 `backup.keep-daily`（7）和 `backup.keep-shutdown`（5）份，频繁重启不会把每日备份挤掉（旧版本配置里的 `backup.keep` 在这两项没写时对每一类照旧生效，升级不会删掉原本要保留的备份）；没写完的备份不会留下。
- 玩家档案 `data/players/<uuid>.json` 读不出来（被清空、手改出语法错误）时不会被覆盖：原文件原样保留，旁边另存一份 `<uuid>.json.corrupt-<时间>`，该玩家在修好之前无法登录（提示联系管理员）。修好原文件即可正常登录，删掉它则重新开号。这期间交易行不会卖出或退回他的挂单，等档案修好再照常处理；必须当场结算的改动（失踪结算、护航结算、保险理赔、悬赏、关服时送回的装备）按发生顺序记进旁边的 `<uuid>.json.unsaved`（控制台同时报错），每行写明要怎么改：`+n` / `-n` 是在当前值上加减，`= 值` 是直接替换，物品是完整的 JSON。这个文件在一天，该玩家就无法登录，自然也拿不回档案里因崩溃留下的护航托管款（`escortEscrow`，开服时控制台会列出）：修好档案后把每一行按顺序改进去，再删掉 `.unsaved`，不用重启，剩下的托管款在他下次上线时退回。要重新开号就把档案和 `.unsaved` 一起删掉。`data/market.json` 读不出来时交易行暂停开放（打开时提示联系管理员），文件不会被改写，修好后重启即可恢复。

修改后 `/cv reload` 生效（地图与物品新增后建议重启一次，以便重新生成资源包）。

`items.yml` 写坏（YAML 语法错误、缺少 `items` 段、有物品解析失败）时整个文件都不会生效：`/cv reload` 会报错并继续使用原来的物品表，开服时读坏则 Craftov 直接停用并在日志里写明原因，修好再重启。只要有一个物品无效整个文件就不生效（以前的版本会跳过它），更新插件前先在日志里搜一下 `Invalid item`。服务器上的 `items.yml` 只在缺失时才从 jar 复制，更新插件不会替换它：刀还是旧格式（`hits-normal` / `player-damage`，没有 `damage`）时开服日志会逐把警告，这样的刀照样能用，但按穿透 1 结算，说明和能否交易也还是旧的（商人会继续卖开山刀和爪刀），备份后换成 jar 里的新文件再重启。文件请存成 UTF-8；用其他编码（例如记事本的 GBK）保存的仍能读取，但中文会变成乱码，日志里会有警告。删掉或改名某个物品 ID 后，玩家身上（包括胸挂、背包里）的这件物品会在下次进入大厅时存进仓库邮箱，断线失踪时也一样不进遗体而是进邮箱；安全箱里的显示为「未知物品」，点一下移入邮箱；配装方案里的会列在「没有放上」里。邮件领取后在仓库里看不到，但记录还在，把 ID 恢复并重启后就能从仓库取回。

更新插件 jar 请整服重启，热重载（Paper 的 `/bukkit:reload confirm`，1.21.11 上 `/reload` 是原版的数据包重载；或插件管理器重载）不在支持范围内。插件关闭时会移除自己加在每个玩家连接上的网络钩子、清空罗盘标记，所以重载后在线玩家应当不用重连就能继续开火、用中键开手电，罗盘也只显示新标记，但这些还没有在真人客户端上确认过。另外 BetterHud 没有注销罗盘标记来源的接口，每次重载都会在 BetterHud 里留下一个不再返回任何标记的旧来源，旧插件也因此留在内存里。

正式服请保持 `online-mode=true`（`server/setup.sh` 不带 `--local` 时的默认值）。离线模式下没有人核对玩家是谁：离线 UUID 只由名字算出，任何人在离线启动器里填上别人的名字（包括服主），就能通过白名单、登进那个人的账号、处置他的仓库；那个账号是 OP 时还能用 `/op`、`/stop` 和全部 `/cv` 管理指令。插件也分辨不出谁是小号，交易行的等级要求、同 IP 限制和每日收入上限只能提高用小号转钱的成本。

离线模式下 Craftov 开服时会在日志里警告，并且只让 OP 账号从 `security.admin-addresses` 里的地址登录（默认是本机和局域网私有网段，可以写单个地址或 `192.168.0.0/16` 这样的网段，只认数字地址，不解析域名，写错的条目（例如 `192.168.1.300`）会在日志里警告并忽略；写成空列表则所有 OP 都进不来）。从别处登录的 OP 会被拒绝，提示里有对方的地址，管理员确实要从外网登录时把自己的地址加进去。`security.admin-guard` 是 `"auto"`（默认，只在离线模式、且前面没有做正版验证的代理时生效）、`"always"` 或 `"off"`。这只保护 OP：普通玩家的账号，以及用权限插件单独给的 `craftov.admin`，都不在保护范围内。用 frp、ngrok、playit 一类的内网穿透，或不转发真实地址的代理时，所有玩家看起来都来自 127.0.0.1，这时要把 `127.0.0.0/8` 和 `::1/128` 从列表里删掉。

要让外网玩家进来，先在 `server.properties` 里改成 `online-mode=true` 再重启：正版客户端能进，离线启动器进不来。切换后每个玩家的 UUID 都会变成正版 UUID，`data/players/` 里按离线 UUID 存的档案（仓库、余额、等级）不会自动迁移，白名单和 OP 也要重新加。一定要让离线玩家进来时，先装登录插件（AuthMe 一类）；它和 Craftov 的加入流程（发新手物资、传送到大厅、断线重连）是否兼容还没有实测过。

## 开发

```bash
./gradlew jar                 # 构建 build/libs/Craftov-1.0.0.jar
python3 tools/art/build.py    # 重新生成全部贴图、模型、音效与 BetterHud 布局（第一次运行会下载枪声录音，约 190 MB）
./gradlew deployLocal         # 构建并复制到 server/run/plugins
```

- 源码：`src/main/java/net/infnetwork/snowball/craftov/`
- 美术与音效生成器：`tools/art/`（Python + Pillow + numpy/scipy + soundfile，解压录音要 `7z`）。枪声录音由 `tools/art/fetch_audio.py` 下载到 `tools/art/.cache/audio/`（不进 git），每个文件按大小和 SHA-256 校验，不符就报错；已下载的不会再下。编码好的 .ogg 按采样内容的哈希缓存在 `tools/art/.cache/ogg/`，同样的输入总是得到同样的文件，重新构建不会产生无意义的 diff。构建最后运行 `tools/art/audiocheck.py` 检查每个近距离枪声：从峰值衰减到 -20 dB 不超过 30 ms（游戏里是栓动的枪、或用 .30-06 录音的枪放宽到 90 ms：AWR、DM14；SCR 虽然用的是莫辛纳甘录音，但游戏里是 600 rpm 全自动，仍按 30 ms）、前 120 ms 里 250 Hz–1 kHz 至少占 30%、频谱主峰高于 150 Hz，所有枪声文件解码后峰值不超过 -0.5 dBFS，全自动的多发样本（M4C 两发、SV9 / V57 三发）里每发的间隔是 75 / 66.7 ms（误差 2 ms 内）；不通过时构建失败（`python3 tools/art/audiocheck.py <sounds 目录>` 也能单独检查）。改了枪声后可以用 `python3 tools/art/audiopage.py <改之前的 sounds 目录> <改之后的 sounds 目录> tools/shots/out/<名字>.html` 生成一个对比试听页（每把枪每一档的前后对比，外加开枪者音量、从 8 格走到 130 格、隔墙三段按 GunAudio 规则混出来的模拟），音频以 MP3 内嵌在页面里，单个文件就能在任何浏览器里听，同名文件夹里另有 MP3。

### 左键开火的实现

原版客户端按住左键时不会发送任何数据包，除非准星正在“挖”一个方块。所以手持枪械时，服务器会在准星前方约 3 格的空气里只对该玩家放置一小片捕获方块：六个面都长满的幽匿脉络（资源包里贴图透明，敲击、脚步、落地音效静音，枪的挖掘速度为 0 所以永远挖不坏），并用资源包着色器隐藏方块选框。它没有碰撞，身体在里面既不会被拖慢，下落也不会顿住（以前用的蛛网会），而它的选框是贴着格子六个面的薄板，准星进入这一格、或者就从这一格里出发，都会先碰到它。准星前 3.7 格内有实体（敌人、靶子、物资箱、遗体）时，捕获方块改放到它前面半格（不够半格就尽量靠前，最近到眼睛所在的那一格），让客户端先“挖”到它而不是去打实体：相距 1.3 格以外总能放进去；再近时，只有实体表面已经进了眼睛所在的那一格才放不进去，这时客户端只会发一次攻击，扳机按一下处理。脚边的格子不放，因为客户端会用站着的那一格方块的脚步声代替地板的。按住左键就变成每 tick 一次挥手、松开时一次中止，服务器据此判断扳机按下和松开。松开只认中止包：网络卡顿时挥手会停一阵再一起补到，所以连续 1 秒收不到挥手才当作松开（兜底），而且这种松开不算放开了扳机，半自动枪不会因为卡顿后补到的挥手再开一枪。只有真正的“开始挖”才算扣下扳机：冒险模式下服务器会把每一次挥手都当成对准星所指方块的一次左键，而客户端按 Q、开门、拉拉杆、点某些菜单之后都会挥手，所以服务器在网络层按到达顺序记下“开始挖”和挥手这两种包，把每次左键对回引起它的那个包，挥手引起的不算。右键开镜由物品模型的 `keybind_down` 条件在客户端即时切换姿势。

没有 BetterHud 时会自动改用 BossBar 显示血量、弹药与对局信息；没有 CraftEngine 时玩法照常但没有自定义贴图与音效。
