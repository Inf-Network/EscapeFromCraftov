# Craftov · 我的世界搜打撤

Craftov 是一个 Paper 1.21.11 插件，在 Minecraft 里实现「搜索 · 战斗 · 撤离」玩法：带装备进入地图，搜索物资、对抗 AI 敌兵与其他小队，活着撤离后战利品才真正属于你。

地图、物品、界面、贴图与音效都是原创并由脚本程序化生成，不使用任何现有游戏的素材或名称。枪械模型由 [Quaternius 的 Ultimate Gun Pack](https://opengameart.org/content/low-poly-guns-pack)（CC0 公有领域）转换而来：`tools/art/meshvox.py` 把网格体素化并合并成 Minecraft 能用的方块元素，结果保存在 `tools/art/voxguns/`。

## 一键开服（玩家输入 IP 即可游玩）

需要：Java 25（BetterHud 需要）、`curl`、`python3`、`unzip`。

```bash
./server/setup.sh          # 正式服：正版验证，资源包地址自动探测公网 IP
./server/run/start.sh      # 启动（默认 4G 内存，可用 MEMORY=8G 调整）
```

脚本会自动下载 Paper 1.21.11、CraftEngine 26.9.2、BetterHud，安装 Craftov 并写好配置：

- 资源包由 CraftEngine **托管在 Minecraft 同一个端口**上，玩家进服时自动弹出下载提示，接受后即可游玩，不需要额外开放端口或网盘。
- 公网 IP 检测失败或服务器在 NAT 后面时，用 `./server/setup.sh --ip 你的公网IP或域名` 指定资源包地址。
- 本地测试：`./server/setup.sh --local`（离线模式，资源包地址为 127.0.0.1）。

首次启动会自动生成大厅与内置地图「锈港」（约 1 秒），之后玩家进服就会落在大厅。

## 测试地图「试验场」与测试模式

首次启动除了「锈港」还会生成一张功能测试地图「试验场」（120×104，白天），所有功能都在几步路以内，并且立了告示牌说明。**试验场只对测试模式和管理员开放**：其他玩家在部署菜单里看不到它，`/cv queue` 也排不进去；小队排试验场时每个队员都要有权限，等待期间关掉测试模式的话出发时会被取消。部署菜单默认选第一张非测试图（锈港），上次选过的地图也会重新校验。从南到北依次是：

- **出生区**：4 组出生点（三排同队同区，单排各自分开）。
- **测试军械库**：9 个固定内容的箱子，分别装着全部武器（满弹匣）和配件、弹药、头盔护甲、胸挂背包、医疗品、投掷物、钥匙、物资和收藏品，搜索很快。每局一份。里面的东西都标着「试验场物资」（`/cv items` 领的是普通物品，不算在内）：局内能正常使用，但没有价值，不能存仓库、卖给商人、放进安全箱，也不算收藏和撤离收益；撤离回大厅时会被收走（装在军械库胸挂 / 背包里的自己的物品会还给你，放不下的送到仓库邮箱）。试验场武器只用试验场弹药，自己的枪也装不进试验场弹药（换下来的子弹还是原来那种）；改枪台上试验场武器只能装武器箱里的试验场配件，和自己的配件不能混装。
- **物资箱长廊**：13 种物资箱各一个，品质有加成。
- **门禁室**：三间门禁房，分别要用三种钥匙开门，里面放着保险箱。
- **玻璃房**：普通玻璃会被子弹打碎，遮光玻璃防弹。
- **演练楼**：两层楼加天台，适合小队对抗。
- **坠落台**：5、10、15 格高，用来测试摔伤、骨折和夹板。
- **撤离点**：常驻、限时（开局 2 分钟后开放）、付费 ◈5,000、需拉闸（电闸在西边）、禁止背包、限员 2 人，六种并排。
- **敌兵区**：用墙隔开，有巡逻、驻守和狙击塔。机密和绝密难度下，开局 60 秒后会出现首领「试验场教官」。

在 `config.yml` 中设置 `test.enabled: true` 开启测试模式。开启后所有玩家都能进试验场，也都能用 `/cv items`（大厅菜单和局内战术终端里也有按钮）打开**测试军械库**：免费领取任意物品、加 100 万块币、一键满血，或者模拟受伤（掉血并附加出血和骨折）。管理员不开测试模式也能用这两样。正式服请保持关闭。

## 玩法一览

| 系统 | 说明 |
|---|---|
| 新手指引 | 新玩家进服后按顺序引导：打开战术终端 → 进入个人靶场 → 在改枪台装配件 → 开始行动 → 成功撤离，完成奖励 ◈20,000（已撤离过的老玩家不会看到）。 |
| 大厅 | 作战机库：开始行动、仓库、商人、交易行、干员、护航大厅、收藏室、排行榜站点，以及一个靶场。快捷栏第 9 格是战术终端（右键打开菜单，或 `/cv`）。 |
| 配装 | 你在大厅的物品栏就是下一局的出战装备。物品栏第 2 行是**胸挂格**、第 3–4 行是**背包格**，装备胸挂/背包才会解锁。卸下胸挂/背包时里面的东西会跟着装进去。对局中存活时，在物品栏里把鼠标停在已装备的胸挂/背包上按 Q，会连同里面的东西一起丢出；大厅里和倒地时不能丢，在窗口外点击也不会丢出鼠标上的东西。关上物品栏（或断线）时鼠标上的东西会放回身上，拿起的胸挂/背包会重新装备。身上放不下的物品（比如领取或拆下的东西）在大厅里会放进仓库邮箱，在对局里掉在脚下。用鼠标拿在手上的物品也算携带：阵亡时进遗体，撤离时放回身上（放不下的进仓库邮箱）。 |
| 战备值 | 身上所有装备与物资的总价值。常规 / 机密 / 绝密 三档难度要求不同战备值，难度越高物资越好、敌兵越强、首领出没。 |
| 匹配 | 每张图、每档难度一个匹配池，同一时段排队的所有小队进同一局，互为敌人。单人或三人小队；三人模式可自动补位。排位赛只决定是否计排位分，不影响匹配。凑满小队数（默认 4，不超过地图出生点组数）立即出发，否则最早排队的人等满 30 秒后带上池中所有人出发；多出的小队直接开下一局。开局后不再加人。 |
| 入场运镜 | 镜头从地图上空俯冲到你的小队渗透点。 |
| 武器 | 11 把原创枪械（手枪、冲锋枪、步枪、轻机枪、霰弹枪、射手步枪、栓动狙击），全自动/三连发/单发/栓动/泵动，弹道、后坐力、扩散、伤害衰减、爆头。 |
| 弹药与护甲 | 弹药有 1–6 级穿透，护甲与头盔有 1–6 级防护和耐久（头盔护头，背心护胸腹）。减伤看穿透和防护的差：穿透比防护高 1 级或更多仍挡掉 15%，同级挡 40%，低 1 级挡 60%、低 2 级挡 75%、低 3 级或更多挡 85%（`combat.armor.damage-taken`）。每次中弹都磨损护甲（子弹伤害 × 弹药的护甲损伤 × 0.3，挡住和击穿一样）。耐久在一半以上时全效，低于一半后防护按比例减弱（物品说明里有提示），打空就和没穿一样；一枪要磨掉的耐久超过剩余耐久时，超出的那部分直接打穿。护甲满效时挡住的子弹不会造成出血和骨折，耐久低于一半后就有可能。 |
| 物资搜索 | 右键物资箱后逐格揭示，搜索格有旋转动画和剩余秒数。搜索时间只由品质决定（白 0.6s → 红 3.6s，config.yml 可调），任何箱子都一样。金红物品有专属音效。箱子内容所有人共享，搜空的箱子会变暗。 |
| 伤病与医疗 | 100 点生命、无自然回血。伤口按部位记录（头、胸、腹、左右臂、左右腿），HUD 左下角的人形图实时显示哪里在出血、哪里骨折，战术终端「伤势」页列出每处伤口和对应药品。出血持续掉血；腿部骨折变慢、不能冲刺、跳不高；手臂骨折扩散和后坐力变大、换弹变慢。绷带、止血敷料、夹板、急救包、军用医疗箱、手术包、止痛药、肾上腺素、自救注射器各有不同的使用动作、音效和进度条，使用时移动变慢。生命低于 35 时屏幕边缘泛红并有心跳声。 |
| 体力与负重 | 冲刺和跳跃消耗体力，体力耗尽后暂时不能冲刺；负重超过 25kg 体力消耗更快、移动变慢。物品说明里有重量。 |
| 倒地与救援 | 小队模式下首次致命伤进入**第一次倒地**（60 秒），被救起后再倒地是**第二次倒地**（30 秒），第三次直接阵亡。队友靠近后**潜行或按住右键**即可救援。 |
| 撤离 | 常驻、限时开放、付费、需拉闸、禁止背包、限员 六种撤离点，部分每局随机开放。禁止背包的撤离点不能穿着背包通过，用鼠标拿着装了东西的背包也不行。 |
| 交互 | 钥匙/门禁卡开锁的房间（刷一次本局永久解锁，之后正常开关门）、拉闸开启撤离点、可被子弹打碎的玻璃、手雷/烟雾弹/震撼弹。震撼弹让正对爆点的玩家白屏最多 4 秒（随后渐渐褪去）并耳鸣，背对时较轻、离得远更轻，隔墙无效；全白期间同时附带失明（第一人称被白屏完全盖住，看不到黑雾；切到第三人称 F5 或按 F1 隐藏界面时看到的是黑雾，不能借此躲过白屏），这段时间不能冲刺；敌兵按同样规则被闪，失准最多 2 秒但照样走位还击。 |
| 藏身处 | 大厅菜单「藏身处」：发电机、工作台、医疗站、情报中心四个设施，花块币和搜来的物资升级（其他设施等级不超过发电机）。工作台用零件制作 1–3 级弹药，医疗站制作绷带到手术包，按现实时间计时（下线也算），完成后领取到仓库邮箱；情报中心每小时产出 2,000 / 5,000 / 10,000 块币，最多累积 24 小时。 |
| 赛季通行证 | 行动、击败敌人和完成任务获得的经验同时计入赛季通行证（每 1,000 经验一级，共 40 级）。每级都有奖励：块币、药品、配件，每 10 级一把枪，在大厅菜单「赛季通行证」领取。改 `season.id` 即开启新赛季。撤离的固定 150 经验要带进至少 ◈15,000 的装备才全额发放（不足按比例，裸装撤离只有净收益和击杀的经验；`rank.extract-xp`、`rank.extract-xp-min-gear`）。 |
| 悬赏 | 大厅菜单「悬赏榜」花 ◈10,000 给在线玩家追加悬赏，排位第一的玩家自带 ◈20,000 系统悬赏（只在其以排位赛出发、出发战备值不低于 ◈60,000 时有效，每天最多发一次）。对局开始后所有人都会知道本局的悬赏目标，在行动中击杀目标即可领取全部赏金。 |
| 装备保险 | 开始行动界面打开「装备保险」后，每次出发按装备价值的 8% 为枪械、护甲、胸挂和背包投保。阵亡后投保装备若直到对局结束都没被别人带出，就退回仓库邮箱；被别人带出则归对方。退回的是出发时的样子：胸挂和背包只退空包，枪只带着出发时就装着的瞄具和配件、不超过出发时数量的同种子弹；局内装上的配件、多装的子弹和包里的东西都留在局内。局内改枪、断线重连、把背包丢在地上（里面的枪也算）都不会让投保失效。对局中途服务器关闭也算对局结束，留在遗体、箱子里和地上的投保装备同样退回。 |
| 安全箱 | 放入的物品阵亡也不丢失，可在商人处升级容量（3 → 9 格）。行动中随时能打开，入场运镜途中和阵亡观战时打不开。 |
| 商人 | 购买武器弹药护甲医疗品和配件（只卖到紫色品质，`trader.max-rarity`；金色、红色物品要在局内搜刮或去交易行买，穿透 5 的弹药也能在藏身处工作台制作），回收任意物资，维修护甲（按缺失的耐久收护甲价值的 75%，`trader.repair-rate`；修好再卖不赚钱，`tools/econ/repair.py` 可核对），一键补弹，扩容仓库。 |
| 枪声 | 每把枪单独合成（爆裂、低频冲击、枪管共鸣、枪机两次撞击），每次随机换一个版本。开枪的人听到立体声第一人称版，其他人按距离听到近 / 中 / 远三种版本，隔墙变闷，远处按声速延迟；室内是房间轰鸣、室外是回声尾音，连射时尾音只在松开扳机后出现。还有子弹擦身而过的"啪 / 嗖"、按材质区分的命中声、头盔"叮"、弹壳落地和各枪族的换弹声。 |
| 手感与反馈 | 第一人称冲刺时枪斜放、平移时侧倾、开火时后坐并有枪口火焰（全部客户端即时切换）。其他玩家看到你双手端枪，冲刺 / 换弹 / 倒地时放下。子弹擦身而过屏幕边缘变暗并轻微抖动，受击时准星周围出现方向红弧。墙上留弹孔（30 秒消失），命中有尘土、木屑、火花、血雾，枪口有闪光，每 3 发一颗曳光弹。 |
| 新敌人 | **持盾突击手**（机密起部分守卫替换为盾兵）：手枪加防弹盾，正面打头、躯干、手臂全被挡下，要打腿或绕到侧后。**敌对干员小队**（常规 15% / 机密 35% / 绝密 50% 的对局出现）：沙色迷彩、装备和枪法更好，会在箱子之间移动并搜走最值钱的东西，击败后能拿回。**侦察无人机**（随机事件）：在地图上空巡航，看见你就会悬停在头顶报警并引来 60 格内的敌兵，可以打下来。 |
| 敌兵外观 | 巡逻兵是林地迷彩、背心、头套和耳机；守卫、狙击手、首领是黑色装备加防毒面具。有人类的受伤声和脚步声，倒下后留下穿着原装备的尸体，可搜索。 |
| 瞄准镜与改枪 | 红点（1 倍）、全息（1.5 倍）、3 倍棱镜、4 倍、8 倍狙击镜五种瞄准镜，可在商人「配件」页购买或从武器箱、保险箱、空投里找到。在「改枪台」（大厅菜单、战术终端或 `/cv mod`）装到身上的枪上、或拆下来，装上后枪模上能看到瞄准镜。改枪台还有枪口（消音器、补偿器）、握把（垂直握把）、战术位（战术手电）、弹匣（扩容弹匣）四个配件位，配件会改变后坐、扩散、换弹、移速和弹容，并显示在枪模上（换弹动画里也跟着动）；消音器让枪声变小、没有枪口焰，敌兵要很近才听得到。红点和全息开镜时分划正对准星；3/4/8 倍开镜显示各自的瞄准镜画面（箭头 / 粗细十字 / 密位点）并按倍率放大。手枪只能装红点，DM14 和 AWR 自带 4 倍和 8 倍镜。 |
| 靶场 | 右键大厅东侧射击位的「靶场武器架」进入个人靶场：每人一份独立的射击位，看不到其他玩家。身上的装备先存起来，只留新手刀和「离开靶场」；武器架可免费领取任意枪械和配件，子弹无限（弹匣 / 999）。右键「离开靶场」清空所有靶场物品，原有装备原样归还。靶场内 `/cv` 打开武器架（含改枪台），仓库、商人、交易行、安全箱、配装方案和免费补给要先离开靶场才能用。 |
| 交易行 | 仓库切到“上架”模式即可寄售（虚拟上架，物品离开仓库）。其他玩家可购买；定价接近参考价时**系统买家**也会收购，小服也能卖得出去。参考价 = 物品价值（含耐久、配件、弹匣里的子弹、数量）× 0.85，固定不变，任何成交都不会抬高它；售价最高为参考价的 3 倍（`market.max-price-multiplier`），系统买家最多出到参考价的 1.25 倍，每个卖家的同一种物品每小时最多收 40 笔挂单（`market.virtual-hourly-cap`，按挂单计，不按数量）。列表里的「玩家成交均价」只随玩家之间的成交变化（按单件裸物品折算，偏离参考价 0.5–2 倍的成交不计入，并限制在参考价的 0.6–1.5 倍），仅供参考。玩家之间买卖要求双方账号等级都达到 3（`market.min-buy-level`）：不到 3 级既不能买其他玩家的商品，挂出的商品也只会被系统买家收购；可选：禁止同一 IP 登录过的账号互相购买（`market.block-same-ip`，默认关闭，因为同一局域网 / 家庭的玩家会被误伤）、每人每天从其他玩家处的交易行收益上限（卖给其他玩家的税后收入，加上低于参考价买入其他玩家商品省下的差价；`market.daily-player-income-cap`，默认 0 = 不限）。 |
| 干员技能 | 疾风（战术冲刺）、白鸮（急救脉冲）、回声（声呐标记敌人，仅小队可见）、铁砧（部署防弹掩体）。潜行 + F 释放。 |

| 收藏品 | 带出红色/金色收藏品会登记到收藏室，完成度达到 25/50/75/100% 发放奖励。 |

## 制作自己的地图

不用圈地、不用写坐标，手持工具点方块就行：

1. `/cv editor world mymap_world` 创建一个空的建图世界（或把现成的世界文件夹放进服务器根目录后用同样的命令载入）。
2. 在里面盖好地图，然后 `/cv editor start mymap` 领取工具：
   - **出生点**：点方块放置，潜行 + 右键空气切换组号（同组 = 同一小队的出生位置）。
   - **撤离点**：潜行 + 右键空气切换类型（常驻/限时/付费/需拉闸/禁止背包/限员）。
   - **物资箱**：切换箱子类型（杂物箱、武器箱、医疗箱、保险箱……），朝向跟随视角。
   - **敌兵**（巡逻/驻守/狙击手）、**首领**。
   - **门禁/电闸**：点击铁门设为门禁（切换需要的钥匙），点击拉杆/按钮设为电闸，自动绑定“需拉闸”撤离点。
   - **删除**：删掉 3 格内最近的标记。
   - **扫描箱子**：把附近 64 格内的箱子、木桶等方块一键转换为物资箱。
   - **保存/边界**：右键保存；潜行右键两个角设置地图边界。
3. 所有标记都会以只有编辑者可见的悬浮文字显示。`/cv editor set name 我的地图`、`set minutes 20`、`set time dusk`、`set camera`（入场运镜中心）、`set test true`（设为测试图，只有测试模式和管理员能看到、能排）可修改属性，`/cv editor exit` 保存并退出。

地图保存在 `plugins/Craftov/maps/<id>.yml`，也可以直接编辑（`test: true` 即测试图；`proving.yml` 没写这个键时也按测试图处理）。手改出错（语法错误、拼错撤离点类型等）的文件不会被覆盖：这张图暂时不加载，文件原样保留并另存一份 `<id>.yml.broken`，控制台和管理员进服时会提示；修好后 `/cv reload`，或删掉文件让内置地图在下次开服时恢复默认。

## 配置文件

`plugins/Craftov/` 下：

- `config.yml`：新手装备、难度档、匹配、倒地时长、护甲减伤与耐久（`combat.armor`）、AI 强度（`ai.dazzle` 是敌兵被爆闪 / 震撼弹晃到后的失准）、震撼弹白屏时长与全白期间的失明（`combat.flashbang`）、商人/交易行费率、免费补给等。
- `items.yml`：全部物品（名称、品质、价值、枪械参数、弹药穿透、护甲等级、医疗效果……）。
- `loot.yml`：每种物资箱的类别与品质权重。
- `data/`：玩家档案与交易行数据（JSON）。旧版本的 `market.json` 在开服时会自动清空成交均价和成交记录（旧版本的参考价可能被刷高过），售价超过参考价 3 倍的挂单退回卖家邮箱（手续费不退）。
- `backups/`：玩家数据的 zip 备份。每天一份（`*-auto.zip`，最新一份满 `backup.interval-hours` 才做下一份，重启不会多做）和每次关服一份（`*-shutdown.zip`），分开保留 `backup.keep-daily`（7）和 `backup.keep-shutdown`（5）份，频繁重启不会把每日备份挤掉（旧版本配置里的 `backup.keep` 在这两项没写时对每一类照旧生效，升级不会删掉原本要保留的备份）；没写完的备份不会留下。
- 玩家档案 `data/players/<uuid>.json` 读不出来（被清空、手改出语法错误）时不会被覆盖：原文件原样保留，旁边另存一份 `<uuid>.json.corrupt-<时间>`，该玩家在修好之前无法登录（提示联系管理员）。修好原文件即可正常登录，删掉它则重新开号。这期间交易行不会卖出或退回他的挂单，等档案修好再照常处理；必须当场结算的改动（失踪结算、护航结算、保险理赔、悬赏、关服时送回的装备）按发生顺序记进旁边的 `<uuid>.json.unsaved`（控制台同时报错），每行写明要怎么改：`+n` / `-n` 是在当前值上加减，`= 值` 是直接替换，物品是完整的 JSON。这个文件在一天，该玩家就无法登录，自然也拿不回档案里因崩溃留下的护航托管款（`escortEscrow`，开服时控制台会列出）：修好档案后把每一行按顺序改进去，再删掉 `.unsaved`，不用重启，剩下的托管款在他下次上线时退回。要重新开号就把档案和 `.unsaved` 一起删掉。`data/market.json` 读不出来时交易行暂停开放（打开时提示联系管理员），文件不会被改写，修好后重启即可恢复。

修改后 `/cv reload` 生效（地图与物品新增后建议重启一次，以便重新生成资源包）。

`items.yml` 写坏（YAML 语法错误、缺少 `items` 段、有物品解析失败）时整个文件都不会生效：`/cv reload` 会报错并继续使用原来的物品表，开服时读坏则 Craftov 直接停用并在日志里写明原因，修好再重启。只要有一个物品无效整个文件就不生效（以前的版本会跳过它），更新插件前先在日志里搜一下 `Invalid item`。文件请存成 UTF-8；用其他编码（例如记事本的 GBK）保存的仍能读取，但中文会变成乱码，日志里会有警告。删掉或改名某个物品 ID 后，玩家身上（包括胸挂、背包里）的这件物品会在下次进入大厅时存进仓库邮箱，断线失踪时也一样不进遗体而是进邮箱；安全箱里的显示为「未知物品」，点一下移入邮箱；配装方案里的会列在「没有放上」里。邮件领取后在仓库里看不到，但记录还在，把 ID 恢复并重启后就能从仓库取回。

更新插件 jar 请整服重启，热重载（Paper 的 `/bukkit:reload confirm`，1.21.11 上 `/reload` 是原版的数据包重载；或插件管理器重载）不在支持范围内。插件关闭时会移除自己加在每个玩家连接上的网络钩子、清空罗盘标记，所以重载后在线玩家应当不用重连就能继续开火、用中键开手电，罗盘也只显示新标记，但这些还没有在真人客户端上确认过。另外 BetterHud 没有注销罗盘标记来源的接口，每次重载都会在 BetterHud 里留下一个不再返回任何标记的旧来源，旧插件也因此留在内存里。

正式服请保持 `online-mode=true`（`server/setup.sh` 不带 `--local` 时的默认值）。离线模式下任何人都能用任意名字进服，插件分辨不出谁是小号，交易行的等级要求、同 IP 限制和每日收入上限只能提高用小号转钱的成本。

### 左键开火的实现

原版客户端按住左键时不会发送任何数据包，除非准星正在“挖”一个方块。所以手持枪械时，服务器会在准星前方约 3 格的空气里只对该玩家放置一小片蛛网（资源包里贴图透明、敲击音效静音，没有碰撞，枪的挖掘速度为 0 所以永远挖不坏），并用资源包着色器隐藏方块选框。按住左键就变成每 tick 一次挥手、松开时一次中止，服务器据此判断扳机按下和松开。右键开镜由物品模型的 `keybind_down` 条件在客户端即时切换姿势。

没有 BetterHud 时会自动改用 BossBar 显示血量、弹药与对局信息；没有 CraftEngine 时玩法照常但没有自定义贴图与音效。
