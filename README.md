# Craftov · 我的世界搜打撤

Craftov 是一个 Paper 1.21.11 插件，在 Minecraft 里实现「搜索 · 战斗 · 撤离」玩法：带装备进入地图，搜索物资、对抗 AI 敌兵与其他小队，活着撤离后战利品才真正属于你。

地图、物品、界面、贴图与音效都是原创并由脚本程序化生成，不使用任何现有游戏的素材或名称。枪械模型由 [Quaternius 的 Ultimate Gun Pack](https://opengameart.org/content/low-poly-guns-pack)（CC0 公有领域）转换而来：`tools/art/meshvox.py` 把网格体素化并合并成 Minecraft 能用的方块元素，结果保存在 `tools/art/voxguns/`。

## 一键开服（玩家输入 IP 即可游玩）

需要：Java 25（BetterHud 需要）、`curl`、`python3`、`unzip`。

```bash
./server/setup.sh          # 正式服：正版验证，资源包地址自动探测公网 IP
./server/run/start.sh      # 启动（默认 4G 内存，可用 MEMORY=8G 调整）
```

脚本会自动下载 Paper 1.21.11、CraftEngine 26.9.2、BetterHud，安装 Craftov 并写好配置：

- 资源包由 CraftEngine **托管在 Minecraft 同一个端口**上，玩家进服时自动弹出下载提示，接受后即可游玩，不需要额外开放端口或网盘。
- 公网 IP 检测失败或服务器在 NAT 后面时，用 `./server/setup.sh --ip 你的公网IP或域名` 指定资源包地址。
- 本地测试：`./server/setup.sh --local`（离线模式，资源包地址为 127.0.0.1）。

首次启动会自动生成大厅与内置地图「锈港」（约 1 秒），之后玩家进服就会落在大厅。

## 测试地图「试验场」与测试模式

首次启动除了「锈港」还会生成一张功能测试地图「试验场」（120×104，白天），所有功能都在几步路以内，并且立了告示牌说明。从南到北依次是：

- **出生区**：4 组出生点（三排同队同区，单排各自分开）。
- **测试军械库**：9 个固定内容的箱子，分别装着全部武器（满弹匣）、弹药、头盔护甲、胸挂背包、医疗品、投掷物、钥匙、物资和收藏品，搜索很快。每局一份。
- **物资箱长廊**：13 种物资箱各一个，品质有加成。
- **门禁室**：三间门禁房，分别要用三种钥匙开门，里面放着保险箱。
- **玻璃房**：普通玻璃会被子弹打碎，遮光玻璃防弹。
- **演练楼**：两层楼加天台，适合小队对抗。
- **坠落台**：5、10、15 格高，用来测试摔伤、骨折和夹板。
- **撤离点**：常驻、限时（开局 2 分钟后开放）、付费 ◈5,000、需拉闸（电闸在西边）、禁止背包、限员 2 人，六种并排。
- **敌兵区**：用墙隔开，有巡逻、驻守和狙击塔。机密和绝密难度下，开局 60 秒后会出现首领「试验场教官」。

在 `config.yml` 中设置 `test.enabled: true` 开启测试模式。开启后所有玩家都能用 `/cv items`（大厅菜单和局内战术终端里也有按钮）打开**测试军械库**：免费领取任意物品、加 100 万块币、一键满血，或者模拟受伤（掉血并附加出血和骨折）。管理员不开测试模式也能用。正式服请保持关闭。

## 玩法一览

| 系统 | 说明 |
|---|---|
| 新手指引 | 新玩家进服后按顺序引导：打开战术终端 → 进入个人靶场 → 在改枪台装配件 → 开始行动 → 成功撤离，完成奖励 ◈20,000（已撤离过的老玩家不会看到）。 |
| 大厅 | 作战机库：开始行动、仓库、商人、交易行、干员、护航大厅、收藏室、排行榜站点，以及一个靶场。快捷栏第 9 格是战术终端（右键打开菜单，或 `/cv`）。 |
| 配装 | 你在大厅的物品栏就是下一局的出战装备。物品栏第 2 行是**胸挂格**、第 3–4 行是**背包格**，装备胸挂/背包才会解锁。卸下胸挂/背包时里面的东西会跟着装进去。 |
| 战备值 | 身上所有装备与物资的总价值。常规 / 机密 / 绝密 三档难度要求不同战备值，难度越高物资越好、敌兵越强、首领出没。 |
| 匹配 | 单人或三人小队；三人模式可自动补位；可选排位赛。等待最多 15 秒后出发，人不够也能开。 |
| 入场运镜 | 镜头从地图上空俯冲到你的小队渗透点。 |
| 武器 | 11 把原创枪械（手枪、冲锋枪、步枪、轻机枪、霰弹枪、射手步枪、栓动狙击），全自动/三连发/单发/栓动/泵动，弹道、后坐力、扩散、伤害衰减、爆头。 |
| 弹药与护甲 | 弹药有 1–6 级穿透，护甲与头盔有 1–6 级防护和耐久；穿不透会大幅减伤并磨损护甲。 |
| 物资搜索 | 右键物资箱后逐格揭示，搜索格有旋转动画和剩余秒数。搜索时间只由品质决定（白 0.6s → 红 3.6s，config.yml 可调），任何箱子都一样。金红物品有专属音效。箱子内容所有人共享，搜空的箱子会变暗。 |
| 伤病与医疗 | 100 点生命、无自然回血。伤口按部位记录（头、胸、腹、左右臂、左右腿），HUD 左下角的人形图实时显示哪里在出血、哪里骨折，战术终端「伤势」页列出每处伤口和对应药品。出血持续掉血；腿部骨折变慢、不能冲刺、跳不高；手臂骨折扩散和后坐力变大、换弹变慢。绷带、止血敷料、夹板、急救包、军用医疗箱、手术包、止痛药、肾上腺素、自救注射器各有不同的使用动作、音效和进度条，使用时移动变慢。生命低于 35 时屏幕边缘泛红并有心跳声。 |
| 体力与负重 | 冲刺和跳跃消耗体力，体力耗尽后暂时不能冲刺；负重超过 25kg 体力消耗更快、移动变慢。物品说明里有重量。 |
| 倒地与救援 | 小队模式下首次致命伤进入**第一次倒地**（60 秒），被救起后再倒地是**第二次倒地**（30 秒），第三次直接阵亡。队友靠近后**潜行或按住右键**即可救援。 |
| 撤离 | 常驻、限时开放、付费、需拉闸、禁止背包、限员 六种撤离点，部分每局随机开放。 |
| 交互 | 钥匙/门禁卡开锁的房间（刷一次本局永久解锁，之后正常开关门）、拉闸开启撤离点、可被子弹打碎的玻璃、手雷/烟雾弹/震撼弹。 |
| 藏身处 | 大厅菜单「藏身处」：发电机、工作台、医疗站、情报中心四个设施，花块币和搜来的物资升级（其他设施等级不超过发电机）。工作台用零件制作 1–3 级弹药，医疗站制作绷带到手术包，按现实时间计时（下线也算），完成后领取到仓库邮箱；情报中心每小时产出 2,000 / 5,000 / 10,000 块币，最多累积 24 小时。 |
| 赛季通行证 | 行动、击败敌人和完成任务获得的经验同时计入赛季通行证（每 1,000 经验一级，共 40 级）。每级都有奖励：块币、药品、配件，每 10 级一把枪，在大厅菜单「赛季通行证」领取。改 `season.id` 即开启新赛季。 |
| 悬赏 | 大厅菜单「悬赏榜」花 ◈10,000 给在线玩家追加悬赏，排位第一的玩家自带 ◈20,000 系统悬赏。对局开始后所有人都会知道本局的悬赏目标，在行动中击杀目标即可领取全部赏金。 |
| 装备保险 | 开始行动界面打开「装备保险」后，每次出发按装备价值的 8% 为枪械、护甲、胸挂和背包投保。阵亡后投保装备若直到对局结束都没被别人带出，就退回仓库邮箱；被别人带出则归对方。 |
| 安全箱 | 放入的物品阵亡也不丢失，可在商人处升级容量（3 → 9 格）。 |
| 商人 | 购买武器弹药护甲医疗品和配件，回收任意物资，维修护甲，一键补弹，扩容仓库。 |
| 枪声 | 每把枪单独合成（爆裂、低频冲击、枪管共鸣、枪机两次撞击），每次随机换一个版本。开枪的人听到立体声第一人称版，其他人按距离听到近 / 中 / 远三种版本，隔墙变闷，远处按声速延迟；室内是房间轰鸣、室外是回声尾音，连射时尾音只在松开扳机后出现。还有子弹擦身而过的"啪 / 嗖"、按材质区分的命中声、头盔"叮"、弹壳落地和各枪族的换弹声。 |
| 手感与反馈 | 第一人称冲刺时枪斜放、平移时侧倾、开火时后坐并有枪口火焰（全部客户端即时切换）。其他玩家看到你双手端枪，冲刺 / 换弹 / 倒地时放下。子弹擦身而过屏幕边缘变暗并轻微抖动，受击时准星周围出现方向红弧。墙上留弹孔（30 秒消失），命中有尘土、木屑、火花、血雾，枪口有闪光，每 3 发一颗曳光弹。 |
| 新敌人 | **持盾突击手**（机密起部分守卫替换为盾兵）：手枪加防弹盾，正面打头、躯干、手臂全被挡下，要打腿或绕到侧后。**敌对干员小队**（常规 15% / 机密 35% / 绝密 50% 的对局出现）：沙色迷彩、装备和枪法更好，会在箱子之间移动并搜走最值钱的东西，击败后能拿回。**侦察无人机**（随机事件）：在地图上空巡航，看见你就会悬停在头顶报警并引来 60 格内的敌兵，可以打下来。 |
| 敌兵外观 | 巡逻兵是林地迷彩、背心、头套和耳机；守卫、狙击手、首领是黑色装备加防毒面具。有人类的受伤声和脚步声，倒下后留下穿着原装备的尸体，可搜索。 |
| 瞄准镜与改枪 | 红点（1 倍）、全息（1.5 倍）、3 倍棱镜、4 倍、8 倍狙击镜五种瞄准镜，可在商人「配件」页购买或从武器箱、保险箱、空投里找到。在「改枪台」（大厅菜单、战术终端或 `/cv mod`）装到身上的枪上、或拆下来，装上后枪模上能看到瞄准镜。改枪台还有枪口（消音器、补偿器）、握把（垂直握把）、战术位（战术手电）、弹匣（扩容弹匣）四个配件位，配件会改变后坐、扩散、换弹、移速和弹容，并显示在枪模上（换弹动画里也跟着动）；消音器让枪声变小、没有枪口焰，敌兵要很近才听得到。红点和全息开镜时分划正对准星；3/4/8 倍开镜显示各自的瞄准镜画面（箭头 / 粗细十字 / 密位点）并按倍率放大。手枪只能装红点，DM14 和 AWR 自带 4 倍和 8 倍镜。 |
| 靶场 | 大厅东侧射击位（黄线内）有「靶场武器架」，可免费领取任意枪械和瞄准镜，靶场内子弹无限（弹匣 / 999）。靶场武器不能存进仓库、不能出售，离开射击位自动收回。 |
| 交易行 | 仓库切到“上架”模式即可寄售（虚拟上架，物品离开仓库）。其他玩家可购买；定价接近参考价时**系统买家**也会收购，小服也能卖得出去。 |
| 干员技能 | 疾风（战术冲刺）、白鸮（急救脉冲）、回声（声呐标记敌人，仅小队可见）、铁砧（部署防弹掩体）。潜行 + F 释放。 |
| 排位赛 | 撤离与击败干员加分、阵亡扣分，青铜到传奇七个段位，大厅有赛季榜。 |
| 收藏品 | 带出红色/金色收藏品会登记到收藏室，完成度达到 25/50/75/100% 发放奖励。 |
| 护航 | 老板托管赏金发布护航委托，护航者接取后自动加入其小队；老板成功撤离护航者平分赏金，老板阵亡护航者拿 30%。 |
| 配装方案 | 保存当前配装，下次一键配齐（优先从仓库取，不足的自动向商人购买）。 |
| 免费补给 | 装备几乎为零时可领取一套基础装备（20 分钟冷却），不会卡死。 |
| 局内事件与夜战 | 约 30% 的对局是夜间行动：地图漆黑，敌兵视野减半，但开着战术手电会被更远处的敌兵发现。每局还会在中段随机发生两个事件：停电（需拉闸撤离暂时失效）、炮击（预警 20 秒后红圈内落炮）、敌方增援从地图边缘赶来、红烟标记的空投、首领带护卫转移，聊天栏会告诉你方位和距离。管理员可用 `/cv event <事件>` 手动触发。 |
| 击杀回放 | 阵亡后以击杀者的第一视角重看最后 6 秒（人形替身重演、带曳光和枪声，最后一秒慢放），之后才是结算和观战队友。按 Shift 跳过；`replay.enabled` 可关闭。 |
| 每日任务 | 每天 04:00 刷新 3 个任务（击败敌兵、爆头、近战、首领、干员、搜索、撤离、指定地图、单局收益），完成即发块币和经验，全部完成另有奖励；未完成的可花钱更换。 |
| 断线重连 | 行动中掉线 120 秒内重进会回到原位置；超时视为失踪。服务器正常关闭时行动作废、物资保留。 |

## 操作

| 按键 | 作用 |
|---|---|
| 左键（按住） | 开火；全自动武器按住连发 |
| 右键（按住） | 开镜瞄准（ADS）：枪移到准星下方、扩散变小、移动变慢、视野放大；DM14、AWR 等带倍镜的枪显示瞄准镜并放大约 2.4 / 4.5 倍；松开即腰射 |
| Q | 换弹（弹匣打空时扣扳机也会自动换弹）；潜行 + Q 切换弹种 |
| F | 切换射击模式 |
| 鼠标中键 | 战术手电（需装在战术位）：关 → 常亮 → 爆闪。爆闪会让正对着灯的玩家白屏闪烁、敌兵失准 |
| 潜行 | 静步：完全没有脚步声，敌兵听不到（正常走路 10 格、冲刺 24 格内会被听到） |
| 潜行 + F | 释放干员技能 |
| 右键物资箱 / 遗体 | 搜索 |
| 医疗品拿在手上按住右键 | 使用（自动处理最危险的伤口），战术终端「伤势」查看每个部位 |
| 潜行或按住右键（对倒地队友） | 救援 |
| 快捷栏第 9 格 | 战术终端：伤势、安全箱、撤离点情报、小队状态、技能、放弃行动 |

拿枪时右下角是武器面板（大厅靶场里也有）：弹匣 / 备弹、射击模式、弹种，下面一行提示换弹进度、「[Q] 换弹」或「无弹药」。不能开火时（比如大厅靶场外、正在换弹、没子弹）屏幕下方会说明原因。

## 指令

玩家：`/cv`（菜单）、`/cv deploy`、`/cv stash`、`/cv trader`、`/cv market`、`/cv secure`、`/cv leave`（取消匹配）、`/party invite|accept|leave|kick <玩家>`。

管理（`craftov.admin`，默认 OP）：

- `/cv give <玩家> <物品ID> [数量]`、`/cv money <玩家> <数量>`
- `/cv raids`、`/cv end [对局ID]`（立刻结束）、`/cv tp <对局ID>`（旁观）
- `/cv injure <玩家> <head|chest|stomach|left_arm|right_arm|left_leg|right_leg> <light|heavy|fracture>`（测试伤势）
- `/cv reload`（重载配置、物品、掉落表、地图）、`/cv lobby`

## 制作自己的地图

不用圈地、不用写坐标，手持工具点方块就行：

1. `/cv editor world mymap_world` 创建一个空的建图世界（或把现成的世界文件夹放进服务器根目录后用同样的命令载入）。
2. 在里面盖好地图，然后 `/cv editor start mymap` 领取工具：
   - **出生点**：点方块放置，潜行 + 右键空气切换组号（同组 = 同一小队的出生位置）。
   - **撤离点**：潜行 + 右键空气切换类型（常驻/限时/付费/需拉闸/禁止背包/限员）。
   - **物资箱**：切换箱子类型（杂物箱、武器箱、医疗箱、保险箱……），朝向跟随视角。
   - **敌兵**（巡逻/驻守/狙击手）、**首领**。
   - **门禁/电闸**：点击铁门设为门禁（切换需要的钥匙），点击拉杆/按钮设为电闸，自动绑定“需拉闸”撤离点。
   - **删除**：删掉 3 格内最近的标记。
   - **扫描箱子**：把附近 64 格内的箱子、木桶等方块一键转换为物资箱。
   - **保存/边界**：右键保存；潜行右键两个角设置地图边界。
3. 所有标记都会以只有编辑者可见的悬浮文字显示。`/cv editor set name 我的地图`、`set minutes 20`、`set time dusk`、`set camera`（入场运镜中心）可修改属性，`/cv editor exit` 保存并退出。

地图保存在 `plugins/Craftov/maps/<id>.yml`，也可以直接编辑。

## 配置文件

`plugins/Craftov/` 下：

- `config.yml`：新手装备、难度档、匹配、倒地时长、AI 强度、商人/交易行费率、免费补给等。
- `items.yml`：全部物品（名称、品质、价值、枪械参数、弹药穿透、护甲等级、医疗效果……）。
- `loot.yml`：每种物资箱的类别与品质权重。
- `data/`：玩家档案与交易行数据（JSON）。

修改后 `/cv reload` 生效（地图与物品新增后建议重启一次，以便重新生成资源包）。

## 开发

```bash
./gradlew jar                 # 构建 build/libs/Craftov-1.0.0.jar
python3 tools/art/build.py    # 重新生成全部贴图、模型、音效与 BetterHud 布局
./gradlew deployLocal         # 构建并复制到 server/run/plugins
```

- 源码：`src/main/java/net/infnetwork/snowball/craftov/`
- 美术与音效生成器：`tools/art/`（Python + Pillow + numpy/scipy + soundfile）
- CraftEngine 资源：`src/main/resources/pack/craftov/`（启动时安装到 `plugins/CraftEngine/resources/craftov/` 并自动重建资源包）
- BetterHud 布局：`src/main/resources/betterhud/`（安装到 `plugins/BetterHud/`，并与 CraftEngine 资源包自动合并）
- 无头测试客户端：`tools/bot/`（mineflayer，`npm install` 后 `node test.js`）
- 第一人称/第三人称持枪预览：`python3 tools/art/fpview.py k47`（按客户端同样的变换计算，调枪的位置不用进游戏）

### 左键开火的实现

原版客户端按住左键时不会发送任何数据包，除非准星正在“挖”一个方块。所以手持枪械时，服务器会在准星前方约 3 格的空气里只对该玩家放置一小片蛛网（资源包里贴图透明、敲击音效静音，没有碰撞，枪的挖掘速度为 0 所以永远挖不坏），并用资源包着色器隐藏方块选框。按住左键就变成每 tick 一次挥手、松开时一次中止，服务器据此判断扳机按下和松开。右键开镜由物品模型的 `keybind_down` 条件在客户端即时切换姿势。

没有 BetterHud 时会自动改用 BossBar 显示血量、弹药与对局信息；没有 CraftEngine 时玩法照常但没有自定义贴图与音效。
