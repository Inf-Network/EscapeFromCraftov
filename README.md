# Craftov · 我的世界搜打撤

Craftov 是一个 Paper 1.21.11 插件，在 Minecraft 里实现「搜索 · 战斗 · 撤离」玩法：带装备进入地图，搜索物资、对抗 AI 敌兵与其他小队，活着撤离后战利品才真正属于你。

所有地图、物品、模型、贴图、界面与音效都是原创并由脚本程序化生成，不使用任何现有游戏的素材或名称。

## 一键开服（玩家输入 IP 即可游玩）

需要：Java 25（BetterHud 需要）、`curl`、`python3`、`unzip`。

```bash
./server/setup.sh          # 正式服：正版验证，资源包地址自动探测公网 IP
./server/run/start.sh      # 启动（默认 4G 内存，可用 MEMORY=8G 调整）
```

脚本会自动下载 Paper 1.21.11、CraftEngine 26.9.2、BetterHud，安装 Craftov 并写好配置：

- 资源包由 CraftEngine **托管在 Minecraft 同一个端口**上，玩家进服时自动弹出下载提示，接受后即可游玩，不需要额外开放端口或网盘。
- 公网 IP 检测失败或服务器在 NAT 后面时，用 `./server/setup.sh --ip 你的公网IP或域名` 指定资源包地址。
- 本地测试：`./server/setup.sh --local`（离线模式，资源包地址为 127.0.0.1）。

首次启动会自动生成大厅与内置地图「锈港」（约 1 秒），之后玩家进服就会落在大厅。

## 玩法一览

| 系统 | 说明 |
|---|---|
| 大厅 | 作战机库：开始行动、仓库、商人、交易行、干员、护航大厅、收藏室、排行榜站点，以及一个靶场。快捷栏第 9 格是战术终端（右键打开菜单，或 `/cv`）。 |
| 配装 | 你在大厅的物品栏就是下一局的出战装备。物品栏第 2 行是**胸挂格**、第 3–4 行是**背包格**，装备胸挂/背包才会解锁。卸下胸挂/背包时里面的东西会跟着装进去。 |
| 战备值 | 身上所有装备与物资的总价值。常规 / 机密 / 绝密 三档难度要求不同战备值，难度越高物资越好、敌兵越强、首领出没。 |
| 匹配 | 单人或三人小队；三人模式可自动补位；可选排位赛。等待最多 15 秒后出发，人不够也能开。 |
| 入场运镜 | 镜头从地图上空俯冲到你的小队渗透点。 |
| 武器 | 11 把原创枪械（手枪、冲锋枪、步枪、轻机枪、霰弹枪、射手步枪、栓动狙击），全自动/三连发/单发/栓动/泵动，弹道、后坐力、扩散、伤害衰减、爆头。 |
| 弹药与护甲 | 弹药有 1–6 级穿透，护甲与头盔有 1–6 级防护和耐久；穿不透会大幅减伤并磨损护甲。 |
| 物资搜索 | 右键物资箱后逐格揭示，品质越高搜得越久（白/绿/蓝/紫/金/红），金红物品有专属音效。箱子内容所有人共享。 |
| 伤病与医疗 | 100 点生命、无自然回血；轻度/重度出血、骨折；绷带、止血敷料、夹板、急救包、军用医疗箱（多次使用的治疗量）、手术包、止痛药、肾上腺素、自救注射器。 |
| 倒地与救援 | 小队模式下首次致命伤进入**第一次倒地**（60 秒），被救起后再倒地是**第二次倒地**（30 秒），第三次直接阵亡。队友靠近后**潜行或按住右键**即可救援。 |
| 撤离 | 常驻、限时开放、付费、需拉闸、禁止背包、限员 六种撤离点，部分每局随机开放。 |
| 交互 | 钥匙/门禁卡开锁的房间、拉闸开启撤离点、可被子弹打碎的玻璃、手雷/烟雾弹/震撼弹。 |
| 安全箱 | 放入的物品阵亡也不丢失，可在商人处升级容量（3 → 9 格）。 |
| 商人 | 购买武器弹药护甲医疗品，回收任意物资，维修护甲，一键补弹，扩容仓库。 |
| 交易行 | 仓库切到“上架”模式即可寄售（虚拟上架，物品离开仓库）。其他玩家可购买；定价接近参考价时**系统买家**也会收购，小服也能卖得出去。 |
| 干员技能 | 疾风（战术冲刺）、白鸮（急救脉冲）、回声（声呐标记敌人，仅小队可见）、铁砧（部署防弹掩体）。潜行 + F 释放。 |
| 排位赛 | 撤离与击败干员加分、阵亡扣分，青铜到传奇七个段位，大厅有赛季榜。 |
| 收藏品 | 带出红色/金色收藏品会登记到收藏室，完成度达到 25/50/75/100% 发放奖励。 |
| 护航 | 老板托管赏金发布护航委托，护航者接取后自动加入其小队；老板成功撤离护航者平分赏金，老板阵亡护航者拿 30%。 |
| 配装方案 | 保存当前配装，下次一键配齐（优先从仓库取，不足的自动向商人购买）。 |
| 免费补给 | 装备几乎为零时可领取一套基础装备（20 分钟冷却），不会卡死。 |
| 断线重连 | 行动中掉线 120 秒内重进会回到原位置；超时视为失踪。服务器正常关闭时行动作废、物资保留。 |

## 操作

| 按键 | 作用 |
|---|---|
| 右键（按住） | 开火；全自动武器按住连发 |
| 左键 | 开镜 / 关镜（狙击枪带瞄准镜遮罩） |
| Q | 换弹；潜行 + Q 切换弹种 |
| F | 切换射击模式 |
| 潜行 + F | 释放干员技能 |
| 右键物资箱 / 遗体 | 搜索 |
| 潜行或按住右键（对倒地队友） | 救援 |
| 快捷栏第 9 格 | 战术终端：安全箱、撤离点情报、小队状态、技能、放弃行动 |

## 指令

玩家：`/cv`（菜单）、`/cv deploy`、`/cv stash`、`/cv trader`、`/cv market`、`/cv secure`、`/cv leave`（取消匹配）、`/party invite|accept|leave|kick <玩家>`。

管理（`craftov.admin`，默认 OP）：

- `/cv give <玩家> <物品ID> [数量]`、`/cv money <玩家> <数量>`
- `/cv raids`、`/cv end [对局ID]`（立刻结束）、`/cv tp <对局ID>`（旁观）
- `/cv reload`（重载配置、物品、掉落表、地图）、`/cv lobby`

## 制作自己的地图

不用圈地、不用写坐标，手持工具点方块就行：

1. `/cv editor world mymap_world` 创建一个空的建图世界（或把现成的世界文件夹放进服务器根目录后用同样的命令载入）。
2. 在里面盖好地图，然后 `/cv editor start mymap` 领取工具：
   - **出生点**：点方块放置，潜行 + 右键空气切换组号（同组 = 同一小队的出生位置）。
   - **撤离点**：潜行 + 右键空气切换类型（常驻/限时/付费/需拉闸/禁止背包/限员）。
   - **物资箱**：切换箱子类型（杂物箱、武器箱、医疗箱、保险箱……），朝向跟随视角。
   - **敌兵**（巡逻/驻守/狙击手）、**首领**。
   - **门禁/电闸**：点击铁门设为门禁（切换需要的钥匙），点击拉杆/按钮设为电闸，自动绑定“需拉闸”撤离点。
   - **删除**：删掉 3 格内最近的标记。
   - **扫描箱子**：把附近 64 格内的箱子、木桶等方块一键转换为物资箱。
   - **保存/边界**：右键保存；潜行右键两个角设置地图边界。
3. 所有标记都会以只有编辑者可见的悬浮文字显示。`/cv editor set name 我的地图`、`set minutes 20`、`set time dusk`、`set camera`（入场运镜中心）可修改属性，`/cv editor exit` 保存并退出。

地图保存在 `plugins/Craftov/maps/<id>.yml`，也可以直接编辑。

## 配置文件

`plugins/Craftov/` 下：

- `config.yml`：新手装备、难度档、匹配、倒地时长、AI 强度、商人/交易行费率、免费补给等。
- `items.yml`：全部物品（名称、品质、价值、枪械参数、弹药穿透、护甲等级、医疗效果……）。
- `loot.yml`：每种物资箱的类别与品质权重。
- `data/`：玩家档案与交易行数据（JSON）。

修改后 `/cv reload` 生效（地图与物品新增后建议重启一次，以便重新生成资源包）。

## 开发

```bash
./gradlew jar                 # 构建 build/libs/Craftov-1.0.0.jar
python3 tools/art/build.py    # 重新生成全部贴图、模型、音效与 BetterHud 布局
./gradlew deployLocal         # 构建并复制到 server/run/plugins
```

- 源码：`src/main/java/net/infnetwork/snowball/craftov/`
- 美术与音效生成器：`tools/art/`（Python + Pillow + numpy/scipy + soundfile）
- CraftEngine 资源：`src/main/resources/pack/craftov/`（启动时安装到 `plugins/CraftEngine/resources/craftov/` 并自动重建资源包）
- BetterHud 布局：`src/main/resources/betterhud/`（安装到 `plugins/BetterHud/`，并与 CraftEngine 资源包自动合并）
- 无头测试客户端：`tools/bot/`（mineflayer，`npm install` 后 `node test.js`）

没有 BetterHud 时会自动改用 BossBar 显示血量、弹药与对局信息；没有 CraftEngine 时玩法照常但没有自定义贴图与音效。
